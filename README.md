## 🌱 About This Repository

Welcome to my **Learning Resources** repository!

This repository is my personal knowledge base where I collect, organize, and document the resources I use while learning **programming, computer science, software development, and related technologies**.

Instead of keeping learning materials scattered across different websites, videos, courses, documentation, and books, I organize them here according to **skill → learning source**.

The goal is simple:

> **Learn → Practice → Build → Document → Improve**

This repository will continuously evolve as I learn new technologies and improve my existing skills.
